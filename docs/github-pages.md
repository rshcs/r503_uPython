# Hosting on GitHub Pages

This project is set up to publish documentation generated by MkDocs.

## 1) Install Documentation Dependencies

Use your virtual environment, then install:

```bash
pip install mkdocs mkdocs-material pymdown-extensions
```

## 2) Preview Locally

From repository root:

```bash
mkdocs serve
```

Open `http://127.0.0.1:8000` to preview.

## 3) Build Static Site

```bash
mkdocs build
```

Generated output is in the `site/` directory.

## 4) Publish to GitHub Pages

You can publish in either of these ways.

### Option A: Automatic deployment via GitHub Actions (recommended)

This repository includes workflow: `.github/workflows/docs-pages.yml`.

- Push to `main`.
- GitHub Actions builds and deploys docs.
- GitHub serves the generated site from the `gh-pages` branch.

If GitHub Pages is not already enabled:

1. Open repository **Settings**.
2. Open **Pages**.
3. Set source to **Deploy from a branch**.
4. Choose branch `gh-pages` and folder `/ (root)`.

### Option B: Manual deployment from local machine

```bash
mkdocs gh-deploy --clean
```

This builds and pushes to `gh-pages`.

## 5) Keep Docs Up to Date

- If API changes in `r503u.py`, regenerate function pages:

```bash
python tools/generate_function_docs.py
```

- Review the generated markdown and refine examples/notes if needed.
